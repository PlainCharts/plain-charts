# Overview

Plain Charts is a modular trading platform built to be extended.

The core stays small and stable while tools, studies, adapters, and addons are composed as plain JavaScript modules against a documented API.

## Principles

**Plainness** — The core contains only the infrastructure required to build on. Everything else is composed as modules.

**Modernity** — The platform adopts technologies that expand architectural possibilities rather than preserve historical constraints.

**User centrality** — The platform hands architectural choices back to the user. Systems are composed rather than prescribed.

**Versatility** — The platform provides stable foundations for extension. APIs, modules, scripts, and AI agents can expand its capabilities without requiring core changes.
