# Quick placement

Hover near the right edge of the price scale and a **+** button appears at the price under your cursor.

![The + button menu on the price scale](/images/quick-plus-menu.jpg)

**Left-click** runs the default action. Right-click opens a menu with more, all at that exact price:

- Place an order (buy limit, sell stop, or the full order dialog)
- Draw a horizontal line
- Add an alert

Set the left-click default in **Settings → Chart → Scales → Plus default action**.

![Configuring the plus button](/images/quick-plus-settings.jpg)
