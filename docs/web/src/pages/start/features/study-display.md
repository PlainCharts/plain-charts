# Study display

The charting engine draws a study three ways:

- **Overlay** — On top of the price chart.
- **Pane** — In its own pane below.
- **Histogram** — As bars.

![A compared symbol in a pane, drawn as a line](/images/pane-candles.jpg)

A pane can also display a different symbol, allowing you to compare it with the symbol you are trading.

Choose how the compared symbol is drawn in the pane settings:

- **OHLC candles**
- **Line** — Draw through any price point: open, high, low, or close

![Pane compare settings](/images/pane-settings.jpg)

## Quick actions

![The same pane drawn as candles](/images/pane-line.jpg)

Set quick-action colors for **normal**, **high**, and **low**. The pane's quick-action button then cycles the price source from normal to high to low.

That lets you compare highs or lows against the main chart on the fly, without opening the settings dialog.
