# AI Workspace

Open the **AI Workspace** from the **Workspace manager**.

Plain Charts includes full AI integration. Enable or disable it, and configure its safety controls, in **Settings → Assistant**.

![The AI Workspace, with the agent marking chart levels](/images/ai-workspace.jpg)

The assistant works through the app's own API, so it can access anything the API exposes. This machine-readable architecture gives both you and the AI a shared environment for understanding and interacting with charts.

The assistant can read charts, interact with chart objects, resolve the location of selected objects, and access your studies and drawings.

This makes it an active trading companion, not just a chatbot. It can analyze market conditions and, if you allow it, execute trades.

That power requires care. Safety controls gate sensitive API calls behind additional confirmation, and order execution is disabled by default.

![Assistant permissions in Settings](/images/ai-assistant.jpg)

For more, see [The AI assistant](/docs/ai/assistant) and [The AI Workspace](/docs/ai/ai-workspace).
