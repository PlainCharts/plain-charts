# Quick buttons

Turn a common action into a **quick button** you can fire with a click, a hotkey, or both.

Access quick buttons creation dialog by clicking on the gear button next to **Buy** and **Sell** in the **Order dialog**.

![Quick buttons in the Order dialog](/images/quick-buttons.jpg)

Each action is written in plain language from a command vocabulary. Chain commands with **and** to build combinations:

```
close partial 2 and move stop be +2
```

![Editing a quick action script](/images/quick-buttons-script.jpg)

Expanding the vocabulary keeps your execution flexible, adapting to how you trade. Save and load your quick actions as templates.
