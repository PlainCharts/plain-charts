# Tool tips

Small tools and shortcuts that let you work without leaving the chart.

## Labels

Add a label in either of two ways:

- Select a drawing, click **Add text**, and enter your label.
- Double-click the drawing and enter the text in the dialog.

To reposition a label later, select the drawing and right-click its text to open the position controls.

![The label position controls on the chart](/images/label-position.png)

Most label editing stays on the chart, without opening a dialog.

## Slice tool

Some drawings include additional tools. Right-click either a horizontal line and choose **Slice**.

![The Slice option in the drawing right-click menu](/images/slice-tool.png)

The Slice tool shortens an existing trend line, ray, or horizontal line. It's useful when a level has been crossed and no longer needs to extend beyond that point. The line is trimmed, while any attached label remains intact.

## Level line tool

The **Level line** combines a horizontal ray with automatic slicing.

![The level line tool and a mitigated level on the chart](/images/level-line.png)

Use it to mark levels that end the moment price reaches them. Instead of extending through the candles, the level stops exactly where it was mitigated.
