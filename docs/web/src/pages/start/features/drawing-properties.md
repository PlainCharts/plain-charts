# Drawing properties

Select a drawing to reveal its quick actions in the lower-right corner of the screen. The available actions depend on the selected drawing.

Select multiple drawings to edit shared properties across all of them at once.

## Properties

Open the **Properties** dialog to edit appearance, including:

- Color
- Opacity
- Thickness
- Line style

![The drawing color picker and styling options](/images/drawing-properties.png)

## Color templates

The color picker lets you build your own color templates.

- Click **New row** to create a row, then **+** to add colors.
- Stack multiple rows to organize different palettes.
- Click the **star** to mark a color as a favorite.

This gives you organized color palettes with favorites that are always within reach.
