# Watchlist

Track symbols with live quotes in the **Watchlist**.

![The Watchlist with customizable columns](/images/watchlist.jpg)

Add as many symbols as you need, and group them into **sections** to keep the list sorted.

Rearrange rows and columns however you like, choose which columns show (Last, Change, Bid, Ask, Spread, and more), and sort as you please.

Create and manage multiple lists from the **Watchlist** dropdown. It's also where you add alerts to an existing list.

![Managing watchlists from the dropdown](/images/watchlist-lists.jpg)

For more, see [Watchlist](/docs/concepts/watchlist).
