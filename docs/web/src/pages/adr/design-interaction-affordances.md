# Interaction: Affordances

> Interfaces create affordances, and repeated affordances become habits.

## User challenge

An interface does not determine behavior.

It shapes what actions are easy to notice and repeat.

Representation answers:

"What can I see?"

Affordance answers:

"What does the interface invite me to do?"

```text
Visible action > Repeated interaction > Habit
```

A stop line invites dragging.

A P&L display invites monitoring.

A close button invites intervention.

The interface does not force these actions.

It makes them available.

## Architectural question

What actions should the interface continuously invite?

## Design & solution

The trader defines the environment.

The platform provides the ability to compose it.

Default state:

```text
No imposed signals.
No required actions.
No fixed workflow.
```

The user adds the tools, views, and controls that support their process.

The interface only presents the questions the trader chooses to ask.
