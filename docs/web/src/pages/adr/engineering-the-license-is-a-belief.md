# The license is a belief

## Challenge

A license can be chosen for business reasons.

It can also be chosen because it matches a philosophy.

A license encodes a belief.

It answers: What should happen when others build on this work?

The choice is not only legal.

It is about what kind of commons you want to create.

The license also depends on the ecosystem.

Legal freedom means little if the platform itself limits what can be built.

## Solution

Choose both:

```text
Technical freedom + Legal freedom
```

For this project:

```text
AGPL + General-purpose ecosystem
```

AGPL preserves the commons across derivatives.

A general-purpose stack preserves the freedom to build.

## Two types of freedom

Software freedom has two dimensions.

```text
Technical freedom

Can you build, modify, and extend?

Legal freedom

Can others remove those freedoms from future versions?
```

An ecosystem can limit freedom through:

```text
Technical limits:
- restricted APIs
- closed architecture
- sandboxing

Legal limits:
- no modification
- no redistribution
- proprietary derivatives
```

Both matter.

## Copyleft philosophy

The difference is what happens after a derivative work exists.

```text
MIT

You can build on the commons
and make the result proprietary.


GPL

You can build on the commons
but derivatives remain open.


AGPL

The same principle applies
even when software is provided as a service.
```

Permissive licenses prioritize the freedom of the next author.

Copyleft licenses prioritize preserving the freedom of the entire commons.

Both recognize the author's contribution.

They disagree on whether future users should inherit the same freedoms.

## Public land analogy

AGPL code is public land with a covenant:

- You can camp there — use it, build on it, run it.
- You cannot fence it — close-source your modifications.
- You cannot claim it as private property — remove it from the commons.
- The next person receives it as you found it, or better if you improved it — never worse, never gated.
- Your use does not reduce anyone else's right to use it.
- It is not rented, leased, or a trial — it is held in common.

The goal of copyleft is not to prevent building.

It is to prevent the commons from shrinking.

Every generation receives the same freedoms that made the work possible.
