# Commercial

## User challenge

Should a trading client optimize for focus or engagement?

A commercial ecosystem can add value.

It can also take over the workspace.

## Architectural question

How do you design a client that supports an ecosystem without allowing the ecosystem to dominate the workspace?

## Design & solution

The terminal is a kit, not a finished product.

The user assembles the workspace from opt-in components.

```text
Workspace
Appearance
Tools
Studies
Addons
Connectivity
Engine
```

Each part is a library.

Each part can be replaced, extended, or shared.

The app is only one consumer of the platform.

The ecosystem does not own the surface.

The user does.

A commercial layer becomes another extension, not the foundation.

That keeps the workspace focused while allowing an ecosystem to grow around it.
