There are multiple ways you can contribute to this project.

## Report a bug

Open an issue with enough detail for us to reproduce the problem, or submit a pull request if you've already prepared a fix. Every report and contribution helps improve the project for everyone.

Search existing issues before opening a new one. If you don't find a match, open a new issue for a single bug and include clear steps to reproduce it.

## Build a piece

The platform is modular, so most contributions are new components such as studies, drawing tools, broker or data source integrations, and Node host add-ons. Submit your work as a GitHub pull request so it can be reviewed and shared with the community.

## Create Themes

Help customize the platform by creating chart or application themes.

## Add a translation

Translations are always welcome. We use Weblate so contributing is painless. Just click the badge above to jump in.

## Improve Documentation

Help improve the documentation by fixing errors, adding examples, or expanding existing guides. Documentation is written in Markdown (.md) and built with Astro.

## Propose a feature

If you're proposing changes to the core platform, please open an issue first to discuss the design and implementation.

Self-contained modules, such as studies, drawing tools, broker or data source integrations, Node host add-ons, and themes, do not require prior approval. Build your contribution and submit it as a GitHub pull request.

## Create Your Workflow

The best contribution is the one you build for yourself. Combine modules, tools, and configurations to create a trading system that matches your thinking. In the end, this is what Plain Charts is all about.
